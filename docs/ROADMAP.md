# Roadmap

Each feature is built with `/build-feature` and logged in `docs/agent-log/`.

| # | Feature | Status |
|---|---------|--------|
| 1 | **Book search.** Search Open Library by title or author and show results with cover, title, author and year. | In progress |
| 2 | **Data layer and shelves.** Set up Drizzle with libSQL. Add a book from search to a shelf: Want to read, Reading, or Finished. | Not started |
| 3 | **My shelves page.** See books grouped by shelf and move them between shelves. | Not started |
| 4 | **Reading progress.** Log the current page for books on the Reading shelf. Record start and finish dates. | Not started |
| 5 | **Yearly goal.** Set a goal for books this year and see progress toward it. | Not started |
| 6 | **Stats page.** Charts for books finished per month, pages read, and favorite authors. | Not started |
| 7 | **Deploy.** Ship to Vercel with a Turso database and add the live link to the README. | Not started |

Stretch ideas: ratings and short reviews, import from a Goodreads CSV export, a public read-only profile page.
